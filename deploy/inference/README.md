# Local inference

Review `install-ollama.sh` for the target bind address and model. `enable-intel-vulkan.sh` is optional and hardware-specific.

Set `DLP_UPSTREAM_BASE_URL`, `DLP_ALLOWED_MODELS`, and `DLP_DEFAULT_MODEL` for your provider. Compose reaches host inference using `host.docker.internal`. Prove local inference and the managed policy path before external commissioning. No host inventory, passthrough mapping, or live performance record is included.
