# Repository controls

The repository is private and uses `main`. GitHub Actions validates the reference implementation and documentation. Repository ownership, plan limitations, branch-protection settings, and past acceptance records from another installation are not inherited here.

Review the actual repository settings before relying on enforced pull-request reviews, status checks, linear history, or restrictions on force pushes/deletion. CI success alone does not prove those controls are enabled. Keep source changes focused, validate them, and push promptly.
